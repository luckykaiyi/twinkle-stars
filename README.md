# Twinkle Stars · 打卡挑战

亲子累计打卡小工具：家长把格子标成「可点亮」，宝宝亲手点亮星星，攒满即可兑奖励。  
纯前端单页，数据只保存在当前设备浏览器本地，无需注册、无后端。

用浏览器打开 `index.html` 即可；也可部署到静态托管（如 GitHub Pages）。

---

## 适合做什么

通用的亲子任务奖励，任务内容由家长配置，例如早睡、阅读、刷牙等。

核心节奏：**家长标「可点亮」→ 宝宝点亮星星 → 达标兑奖励**。已得星不会因中断清零。

---

## 快速上手

1. 顶栏切到 **家长**
2. **设置**（可选）：昵称、皮肤、童锁（默认 `1234`）
3. **新建任务**：任务名、目标奖励、目标颗数（3–60，默认 7）
4. **打卡**：点格子切换状态（空白 → 可点亮 → 已点亮）；也可预览奖状 / 星星特效
5. 点顶部 **交给宝宝**（开启童锁），让宝宝点闪着的格子
6. 达标后查看 / 保存奖状；新挑战需先 **归档** 再新建

---

## 打卡规则

- 格子是 N 个星槽，不绑固定日历
- **按顺序打卡**，不能跳过中间格子
- 标成「可点亮」时记下当天日期；家长可点日期修改（补记 / 修正）
- 同一天可有多颗星，重复日期会提醒
- 攒满 N 颗即可兑 **目标奖励**
- 宝宝点亮最后一颗会播礼物盒惊喜动画；奖状需再点「查看奖状」
- 家长端打满时会直接弹出奖状预览

---

## 宝宝页 / 家长页

**宝宝页**：显示当前未归档任务（含已完成尚未归档）。可点亮、看进度与奖状。

**家长页**（顶栏切换；不经「交给宝宝」则无童锁）：

- **交给宝宝**：顶栏按钮，锁定为宝宝页，退出需童锁
- **当前任务**：新建 / 历史、改任务信息、打卡、归档
- **预览**：奖状、普通星星特效、超级星星（礼物盒）特效
- **调试模式**（默认关）：开启后可一键打满 / 清空，并备份当前数据；关闭时可选择是否恢复备份
- **设置**：昵称、皮肤、童锁；可 **清空全部数据** 恢复初始状态

---

## 奖状

达标后可在宝宝页或家长页预览。点「保存奖状」按系统提示存入相册或下载到本地。

---

## 数据说明

- 保存在浏览器本地（`localStorage`，键名 `twinkle-stars-v2`）
- **无云同步**。换浏览器、清站点数据或换设备会导致进度丢失
- 童锁用于防误触，不是加密；明文存在本机
- 本版本与旧版（`twinkle-stars-v1`）**存储隔离**：互不读写。部署本版后，旧进度不会自动带过来，页面会以空白状态开始；若再打开旧版页面，旧数据仍在。需要彻底清除时，可在设置里「清空全部数据」
