# Twinkle Stars · 打卡挑战

亲子日常连续打卡小工具：点亮星星、攒进度、兑奖励。  
纯前端单页（`index.html`），数据保存在浏览器本地，无后端。

## 功能

- **宝宝页 / 家长页**（家长页带童锁）
- **连续打卡**：点亮星星＝完成，再点＝取消；支持一键打满 / 一键清除
- **任务可配置**：任务名、奖励、开始日期、连续天数
- **宝宝资料**：昵称（鼓励文案与奖状按昵称生成）
- **皮肤**：蓝色 / 粉色 / 绿色 / 黄色 / 紫色
- **奖状**：完成后可预览并保存为图片

## 使用方式

用浏览器打开 `index.html` 即可。

## 说明

- 数据仅保存在当前设备浏览器本地
- 换浏览器或清除网站数据会导致进度丢失
