# Twinkle Stars · 打卡挑战

亲子连续打卡小工具：家长确认过关、宝宝亲手点亮星星、攒进度兑奖励。  
纯前端单页，数据保存在当前设备浏览器本地，无需注册、无后端。

用浏览器打开 `index.html` 即可使用；也可部署到静态托管（如 GitHub Pages）后访问。

---

## 适合做什么

适合需要「家长确认、宝宝参与」的日常挑战，例如：

- 夜间不尿床
- 按时刷牙 / 睡觉
- 其他可按天连续完成的小目标

核心节奏：**家长把某天标成「可点亮」→ 宝宝点击点亮星星 → 连续集齐后兑换奖励**。

---

## 快速上手

1. 打开页面，切到 **家长**
2. 在 **基础设置** 填写昵称、选皮肤（可选）
3. 在 **任务设置** 填写任务名、奖励、开始日期、连续天数，点 **保存任务**
4. 在 **每日打卡** 把过关的天点成「可点亮」（空白 → 可点亮）
5. 切到 **宝宝**，让宝宝点闪着的格子，亲手点亮星星
6. 连续全部点亮后，可查看 / 保存奖状

---

## 宝宝页

宝宝主要看进度、亲手点亮星星。

| 内容 | 说明 |
|------|------|
| 目标奖励 | 完成后可兑换的奖励 |
| 进度环 | 当前连续已点亮天数 / 目标天数 |
| 星星进度 | 每一天一格；闪动的空星 = 可点亮 |
| 点亮 | 点击可点亮格子，会播放全屏星星庆祝动效 |
| 奖状 | 全部完成后可查看奖状 |

未设置昵称时，文案使用通用称呼「宝宝」；设置后会按昵称生成鼓励语和奖状。

---

## 家长页

顶部可在 **宝宝 / 家长** 之间切换（开启宝宝模式后除外）。

### 1. 基础设置

- **宝宝昵称**：用于标题、鼓励文案、奖状（占位提示「小宝子」）
- **皮肤风格**：蓝 / 粉 / 绿 / 黄 / 紫，立即生效
- **保存设置**：保存昵称等
- **恢复默认设置**：清空昵称，皮肤恢复蓝色；**不影响**任务与打卡

### 2. 任务设置

- 任务名称、奖励名称、开始日期、连续天数（3–60）
- **保存任务**：保存或更新任务
- **清空任务**：只清空任务配置和打卡记录；**不影响**昵称、皮肤、童锁

进度按「从第 1 天起连续已点亮」计算；中间有未点亮的天，连续会中断。

### 3. 每日打卡

点格子循环切换状态：

**空白 → 可点亮 → 已点亮 → 空白**

| 状态 | 含义 |
|------|------|
| 空白 | 尚未过关 / 未处理 |
| 可点亮 | 家长已确认，留给宝宝点（也可家长再点一次直接点亮） |
| 已点亮 | 计入连续进度 |

快捷按钮：

- **一键可点亮**：未点亮的天都标成可点亮，方便宝宝逐个点
- **一键打满**：全部直接点亮（家长代操作）
- **一键清除**：清空全部打卡标记
- **预览奖状**：预览当前奖状样式

任意挑战日都可标「可点亮」（不限今天），适合「第二天才能确认是否过关」的场景。

### 4. 家长设置（宝宝模式 / 童锁）

- **宝宝模式**开关：开启后只显示宝宝页，顶部切换隐藏
- 右上角出现 **家长** 悬浮按钮；输入童锁密码可退出宝宝模式，恢复自由切换
- **修改童锁密码**：点开后再输入 4 位数字并保存（默认 `1234`）
- 宝宝模式关闭时：可在宝宝页与家长页之间自由切换，无需密码

建议：把设备交给宝宝前，先开启宝宝模式。

---

## 奖状

连续目标全部点亮后：

- 宝宝页可点 **查看奖状**
- 家长页可在每日打卡下方 **预览奖状**
- 支持 **保存奖状** 到本地 / 相册

## 添加到手机桌面（可选）

用 Safari（iPhone / iPad）打开网站后：

分享 → **添加到主屏幕**

会使用项目自带的星星图标，名称默认为「打卡挑战」。

---

## 数据说明

- 所有数据存在当前浏览器的本地存储（`localStorage`）
- 不会上传服务器
- 更换浏览器、清除网站数据，或换设备，都会导致进度丢失
- 「清空任务」与「恢复默认设置」范围不同，互不影响对方负责的数据
