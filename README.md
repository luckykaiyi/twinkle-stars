# Twinkle Stars · 打卡挑战

亲子打卡小工具：家长确认过关、宝宝亲手点亮星星、攒进度兑奖励。  
采用 **累计打卡**：攒满目标颗星即可兑奖，已得星不会清零。同时只推进一个主任务，历史可追溯。  
纯前端单页，数据保存在当前设备浏览器本地，无需注册、无后端。

用浏览器打开 `index.html` 即可；也可部署到静态托管（如 GitHub Pages）。

---

## 适合做什么

通用的亲子任务奖励工具，任务内容由家长自行配置，例如早睡、阅读、刷牙等日常习惯。

核心节奏：**家长把格子标成「可点亮」→ 宝宝亲手点亮星星 → 达到目标兑奖励**。

---

## 快速上手

1. 打开页面，切到 **家长**
2. **设置**（可选）：昵称、皮肤、童锁
3. **新建任务**：任务名、目标奖励、目标颗数（默认 7）
4. **打卡**：直接点格子切换状态（空白 → 可点亮 → 已点亮）
5. 点顶部 **交给宝宝**，让宝宝点闪着的格子亲手点亮
6. 达标后查看 / 保存奖状；需要新挑战时先 **归档** 再新建

---

## 打卡规则

- 格子是 N 个星槽，不绑固定日历区间
- **按顺序打卡**：不能跳过中间格子去点后面的星
- 标成「可点亮」时会记下当天日期；家长可点日期修改（方便补记或修正）
- 攒满 N 颗星即可兑 **目标奖励**
- 宝宝点亮最后一颗时播放礼物盒惊喜动画；奖状需手动点「查看奖状」
- 已得星不会因为中断而清零

---

## 宝宝页

只显示 **当前进行中的任务**（含已完成尚未归档的）。

- 目标奖励、进度环、星星格
- 点亮可点亮格子时有全屏庆祝；达标可看奖状

---

## 家长页

首屏只保留高频操作：

- **交给宝宝**：顶栏按钮，打开后只显示宝宝页，退出需童锁
- **当前任务**：新建 / 历史、打卡、归档
- **设置**（顶栏入口 → 全屏面板）：昵称、皮肤、修改童锁

### 当前任务

- **新建任务**（同时只能有一个进行中；若已有会提示先归档）
- 查看进度、改任务名 / 目标奖励（目标颗数创建后按星槽推进）
- **打卡**：点星星切换状态。标成可点亮时带上当天日期，点日期可改这一格；同一天可以有多颗星，重复时只会提醒
- **预览奖状**；调试模式默认关闭，打开后才出现「一键打满 / 一键清空」。开启时会备份数据，关闭时可选择恢复备份或保留当前结果
- **归档任务**：宝宝页不再显示，记录进入历史
- **历史任务**：全屏面板中回顾奖状或删除记录；左上角返回或底部关闭可回主界面

---

## 奖状

达标后可在宝宝页或家长页预览 / 保存。

---

## 数据说明

- 保存在浏览器本地（`localStorage`）
- 旧版连续打卡 / 单任务数据会在打开时自动迁移为累计星槽
- 换浏览器、清站点数据或换设备会导致进度丢失
